## Stack technique

Dear Pages est actuellement construit avec :

- **React** pour l'interface utilisateur
- **JavaScript** pour la logique de l'application
- **Tailwind CSS** pour les styles et le responsive
- **Vite** pour l'environnement de développement
- **Google Books API** pour rechercher et récupérer les informations des livres
- **Open Library** pour les tendances de lecture
- **Firebase** prévu pour l'authentification et les données personnelles de l'utilisateur
- **JSDoc** pour documenter les fonctions et services importants
- **Astro + Starlight** pour cette documentation

## État du projet

Dear Pages est actuellement en cours de développement.

Les fonctionnalités principales sont construites progressivement, et cette documentation évoluera en même temps que l'application.
